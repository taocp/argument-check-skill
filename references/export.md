# 导出论证分析

仅在用户明确要求文件时使用本流程。先完成会话中的最终正文，再将同一份 Markdown 交给脚本；仅转换既有分析时，不重新评价或改写结论。

## 格式与运行

- `markdown`：保存原始 Markdown，保留加粗标记和链接；显示颜色由阅读器决定。
- `png`：生成一张完整长图，不按分析单元分图。
- `pdf`：生成一个按纸张分页的文件，保留可选择文字和可点击链接。

PNG/PDF 使用正文已有的标题、引用、列表、分隔线和强调，将加粗显示为红色加粗。不得额外添加标题、解释、署名、水印、页眉或页脚。链接显示原有可见文字；如需在图中显示网址，先将网址纳入同一份正文。

从本技能目录定位 `scripts/render_analysis.py`，先查看 `--help`。示例：

```sh
python3 <技能目录>/scripts/render_analysis.py <最终正文.md> --format markdown png pdf --output <新输出目录>
```

按用户选择调整 `--format`，不要默认导出全部格式。输出目录须为新目录，避免覆盖既有结果；渲染所用 HTML 和浏览器配置是临时文件，不作为交付物。

仅导出 Markdown 需要 Python。PNG/PDF 还需要 Python-Markdown、Chromium/Chrome 和覆盖正文字符的字体；检查当前机器实际可用的工具，安装缺失项时遵循当前环境的安装规范，不使用写死的机器路径。

## 核验与交付

- Markdown 应与最终正文一致；修改正文后重新导出所有已请求的格式。
- 查看实际 PNG/PDF，核对中文、红色加粗、换行和裁切；PDF 还应检查分页、文字选择与来源链接。长文可用现有 PDF 文本提取工具辅助核对是否漏字。
- 在当前会话保留完整文字并提供导出文件链接，不以文件链接代替正文。
- 渲染失败或尺寸受限时如实说明，保留会话正文；不得为了导出而删减内容、自动分图或用生成式绘图重画文字。
